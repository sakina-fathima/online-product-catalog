# 🛒 Online Product Catalog API

A robust, scalable RESTful backend service built with **Node.js**, **Express**, and **MongoDB Atlas** designed to manage product inventories, categories, pricing attributes, and big data aggregation analytics.

---

## 🚀 Tech Stack

* **Runtime:** Node.js
* **Framework:** Express.js
* **Database & ODM:** MongoDB Atlas, Mongoose
* **Middleware:** CORS, dotenv
